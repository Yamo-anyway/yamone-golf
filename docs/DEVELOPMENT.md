# 단계별 진행

## 이번 작업: 1단계 v0.3.0

기존 v0.2.0을 보존하고 Cloudflare 서버와 새 앱의 사용자·기기 인증 흐름을 구현했습니다. 이 버전은 기존 전체 골프 기능을 이식한 완성판이 아니라, 단계별 개발의 첫 실행 가능한 결과물입니다.

포함: 사용자 생성, 재시작 인증, 개인 코드/QR, 닉네임/언어 변경, 복구 키 복구, 한 활성 기기, 이전 기기 차단, 중복 요청 방지, 로컬 D1 마이그레이션, 광고 정책 함수.

미포함: 실제 Cloudflare 계정 리소스 생성/배포, 원격 Git push, APK·iOS 설치 빌드, 실기기 SecureStore 삭제/재설치 검증, 실제 광고 SDK·배너, 이메일, 기존 DB 이전.

라운드 기능을 구현할 때 광고 SDK 대신 명확한 테스트 어댑터를 먼저 연결하고, 운영 앱에서 테스트 통과 상태를 실제 광고 시청으로 위장하지 않습니다. 서버의 광고 처리 이력 저장은 실제 기능 요청과 함께 구현합니다.

최신 광고 기준은 POLICY.md를 사용합니다. 예전 v0.2 문서의 ‘생성/참여/종료/받기 각각 광고’ 및 ‘4초 polling’은 새 구현의 확정 기준이 아닙니다.
