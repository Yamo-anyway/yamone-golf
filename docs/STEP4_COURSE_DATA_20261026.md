# 4단계 골프장 데이터·관리자 연결 — 2026-10-26

통합 브랜치의 골프장 국가·번역·검색, 데이터 점검, 수집 대기열을 보완했다. 운영 DB 실데이터에 대한 검토·수정·배포 완료를 뜻하지 않는다. 현재 환경의 Wrangler는 인증되지 않아 운영 조회와 반영은 수행하지 않았다.

## 앱

- 전체 ISO 국가 249개의 한국어/영어 이름과 검색 가능한 국가 선택 화면을 제공한다. 관리자 운영 대상은 기존 9개국, 개인 등록은 캄보디아·라오스를 포함한 전체 국가다.
- 새 등록 국가의 기본값과 선택 목록의 우선 국가는 휴대폰 **지역 설정**에서 얻는다. GPS를 사용하거나 사용자 프로필에 국가를 저장하지 않는다. 지역을 얻을 수 없으면 임의의 국가를 추정하지 않는다.
- 공용 검색은 기본 전체 국가이며 국가를 지정해 검색할 수 있다. 다음 페이지는 실제 검색에 사용한 국가·검색어를 유지한다. 이름·주소·지역 및 번역된 값만 검색하며 번역 JSON의 필드 이름을 검색어로 잘못 매칭하지 않는다.
- 요청의 일시적인 `X-Device-Region`과 서버의 `display_name`을 연결한다. 한국 지역 설정은 한국어·영어 병기, 그 외는 확보된 영어·현지어 표기라는 기존 정책을 적용한다. 번역이 없으면 원문을 유지한다.
- 골프장 목록·선택 요약에는 표시명을 쓰고, 편집 입력은 원래 이름을 유지한다. 과거 라운드의 이름·PAR 스냅샷을 최신 골프장 정보로 다시 쓰지 않는다.
- 국가 사용이 중단되면 신규 등록·국가 변경을 저장하기 전에 차단하고, 트랜잭션에서도 다시 확인한다. 기존 라운드의 스냅샷은 보존한다.

기존 복구 모듈의 후속 수정은 Git 변경 이력으로 관리한다. `source-integration-20261026.json`의 해시는 최초 통합한 원본 기준이며 현재 수정본의 해시가 아니다.

## 관리자 데이터 점검

국가별 골프장 화면의 **데이터 점검** 버튼과 인증된 `GET /admin/api/courses/audit?country=KR`를 추가했다.

| 점검             | 의미                                                 |
| ---------------- | ---------------------------------------------------- |
| 국가 미지정·오류 | 기존 빈 국가와 ISO 외/비정규 코드를 구분             |
| 지역 미분류      | 기존 지역 매핑·수동 분류로 결정되지 않은 항목        |
| 번역 누락        | 확보된 원문에 대한 한국어 또는 영어 표기가 없는 항목 |
| 홀·PAR 확인      | 9홀 단위, 코스 수, 홀별 PAR 3~7의 완성도             |
| 코스 이름 중복   | 같은 골프장 안에서 대소문자·정규화 후 같은 코스 이름 |
| 중복 골프장 후보 | 같은 국가·정규화한 원래 이름이 같은 별도 골프장 ID   |

이 점검은 읽기 전용이다. 주소·지점·홀 구성이 다른 같은 이름을 자동 병합하지 않고, PAR·번역·지역을 추측해 채우지 않는다. 후보를 열어 기존 관리자 수정 흐름에서 검토한다. 관리자 로그인은 초기 현황·대시보드 로딩이 끝난 뒤 화면을 열어, 빠른 메뉴 선택이 뒤늦은 로딩에 의해 되돌아가지 않게 했다. 수정이나 검색 후 이전 점검 결과는 숨겨 오래된 집계를 최신처럼 표시하지 않는다.

한 번에 최대 5,000개를 검사한다. 전체 수와 검사 행은 한 SQL 문장으로 같은 스냅샷에서 읽는다. 초과하면 `complete=false`와 일부 검사 표시를 제공한다. 이때 통계·중복 후보는 검사한 범위에 대한 값이다. 상세 후보는 오류 100개, 중복 50그룹(그룹별 ID 최대 8개)까지 표시한다. 삭제 목록은 제외하며 비활성 코스도 검토에 포함한다.

## 수집·가져오기

- Cron의 PH 고정 호출을 제거하고 기존 국가 우선순위 대기열을 사용한다. 지원 대상은 KR·PH·JP·CN·TW·VN·TH·MY·ID다. 과거에 다른 국가 대기열이 남아 있어도 자동 수집 대상으로 고르지 않는다.
- `0012_golfcore_sync_queue.sql`은 없는 국가 대기열만 추가한다. 기존 우선순위·진행 위치·잠금 시각·완료/오류/일시 정지 상태를 보존하며 재적용해도 중복되지 않는다.
- 잘못된 목록 행을 제거한 개수로 진행 위치를 옮기던 동작을 차단했다. 잘못된 페이지는 오류와 원래 위치를 남겨 재시도한다.
- 일부 잘못된 홀이 있는 10/18홀을 필터링해 정상 9홀로 오인하지 않는다. 완전한 9/18홀과 연속된 홀 번호·PAR 3~7만 가져온다.
- 수집은 원본 카탈로그 저장이다. 관리자 검토 후 앱 공용 목록에 반영하는 흐름을 유지한다. 원본 갱신은 검토된 이름·번역·PAR를 덮어쓰지 않으며 같은 GolfCore slug는 같은 공용 골프장에 대응한다.
- 라운드 준비 후 광고 중 골프장이 바뀌거나 비활성화되면 실제 생성 직전과 쓰기 트랜잭션에서 재검사한다. 실패한 생성은 부분 라운드를 남기지 않고 기존 광고 처리 증거를 유지한다.

## 검토 이미지

`design/course-search.png`와 `design/course-search-en.png`는 각각 한국어·영어 앱의 국가 필터 화면이다. 실제 운영 데이터가 아닌 로컬 검증용 골프장으로 캡처했다. `tests/course-data-ui.ts`가 생성하는 `qa/course-data/search-ko.png`·`search-en.png`를 복사한 원본 캡처다.

## 검증과 다음 단계

실행 결과는 `VALIDATION.md` 최신 절을 사용한다. 로컬 검사는 테스트 데이터·격리 D1과 모의 GolfCore 응답으로 수행한다. 실제 운영 데이터 품질 수치나 수집 성공 건수로 재해석하지 않는다.

다음 5단계에서는 인증된 Cloudflare 계정으로 운영 D1 스키마·마이그레이션 이력과 실제 수집 상태를 읽어 대조한다. 운영에는 일부 필드가 수동 적용됐을 수 있으므로 `0010`을 포함한 전체 마이그레이션을 확인 없이 일괄 적용하지 않는다. 새 큐 마이그레이션과 Worker도 아직 운영에 반영하지 않았다. 그 후 국가별 점검 결과를 검토하고 실제 수집·앱 검색을 확인한다.
