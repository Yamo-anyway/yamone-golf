# 2단계 — 홀 입력과 전체 스코어카드

2026-10-26. 기존 통합본을 기준으로 마지막 화면 요청을 반영했다.

## 동작

- 이 홀 삭제는 서버 저장이 아닌 기기의 삭제 초안이다. 확인 후 점수를 비워 보여 주며, 저장을 눌러야 선택된 플레이어의 해당 홀을 삭제한다. 취소는 그 홀의 초안만 버리고 전체 스코어카드로 돌아간다. 다른 홀의 초안과 원본 점수는 보존한다.
- 일반 저장·수정·삭제 저장과 충돌 재확인 후 성공 시 전체 스코어카드로 돌아간다. 저장소 오류·미확정 충돌·차단된 요청은 입력 화면에서 해결한다. 통신 장애 중에는 전송 대기열의 기기 저장에 성공한 경우 카드로 돌아가며, 카드에 전송 대기 상태를 표시한다. 카드 순위는 확인된 서버 기록 기준이다.
- 미저장 상태에서 다른 홀/화면으로 이동할 때의 저장/초안 보관/버리기 선택은 유지한다. 이 확인창에서 명시적으로 선택한 이동은 원래 목적지를 따른다.
- 카드의 홀 제목 또는 플레이어 점수 칸을 누르면 해당 홀 입력으로 이동한다. 종료된 라운드와 기록·신페리오 스냅샷에서는 입력 연결 없이 일반 셀을 표시한다.
- 카드로 돌아갈 때 이미 열린 카드를 재사용해 화면이 중복으로 쌓이지 않도록 했다.
- 스코어 입력·라운드 방·새로고침 버튼을 골프장명 바로 아래 배치했다. 닉네임은 9홀+합계 너비를 쓰는 별도 행이며, 홀/합계 열과 기존 스코어 기호의 폭을 유지한다. PAR 3/5에 별도 색상 줄을 넣지 않는다.
- 선택 홀은 한국어 `1번홀 Par 4`, 영어 `Hole 1 Par 4` 형식이다. 입력 대상 범위/인원 보조 줄을 제거했다.

## 구현 위치

- `src/data/score-offline-core.ts`: 삭제 초안을 영속 보관하는 `stageDelete`.
- `src/ui/scores.tsx`: 저장·취소·충돌 후 복귀, 카드 상단 동작, 홀 선택, 열람 전용 셀.
- `src/ui/locales/ko.ts`, `en.ts`: 홀 표기와 삭제 저장 안내.
- `tests/score-offline.test.ts`: 삭제 초안 재실행·취소·명시적 저장·다른 홀 보존·오프라인 재전송·저장소 오류.
- `tests/scorecard-flow-ui.ts`: 새 전체 흐름과 화면 너비 검사. 기존 점수·오프라인·모바일 UI 검사도 새 복귀 동작을 반영했다.
