# 6단계 라운드 종료 — v0.3.5

## 서버가 판단하는 상태

- `rounds.status/ended_at`: 공동 기록의 종료 여부와 기준 시각.
- `round_endings`: 수동/6시간 무변경 사유, 종료 사용자(자동은 null), 기준 종료 시각, 실제 처리 시각. 라운드당 한 행.
- `round_completions`: 종료 당시 삭제되지 않은 각 Player Slot의 유효 점수 홀 수, 라운드의 9/18홀 설정, 완료 여부. null과 행 부재는 미입력.
- `record_version`: 점수의 실제 변경, 플레이어 변경, 참여 시 증가. 종료 확인 중 다른 기록 변화가 있으면 재확인.
- `permission_version`: 종료 권한 부여/회수의 충돌 방지. 권한 변경은 점수 활동 시간을 늘리지 않음.
- `round_lifecycle_mutations`: 사용자·요청 ID·요청 해시·내용·시각을 보관. 동일 요청 재시도는 실행을 반복하지 않음.

종료 시 라운드, Player Slot, 점수, 참여자는 유지합니다. 모든 해당 라운드의 active_round_users를 삭제하고 pending 초대만 cancelled로 바꿉니다. 이 모든 변화와 완료 상태 저장은 D1 batch 한 트랜잭션입니다. 이전 종료 요청 재전송이 나중에 시작한 다른 라운드의 참여를 해제하지 않습니다.

## 권한과 확인

생성자에게 초기 can_end=1을 줍니다. 생성자만 기존 참여자의 종료 권한을 위임·회수하며 자신의 권한은 회수할 수 없습니다. 위임받은 사람이 재위임하는 기능은 없습니다. 활성 기기, 참여, can_end, 기록 버전, 아직 진행 중이며 기한 이내인 상태를 실제 쓰기에서 다시 확인합니다.

이전 종료 요청이 성공한 뒤 응답만 유실되면 같은 요청 ID로 종료 시각/완료 상태를 다시 확인합니다. 동일 ID를 다른 내용으로 쓰면 거절합니다. 이미 종료된 라운드는 참여자에게 현재 종료 상태를 돌려줍니다. 추가 광고 이력을 생성하거나 요구하지 않습니다.

## 자동 종료와 활동 기준

기준은 서버의 마지막 `updated_at + 6시간`입니다. 점수의 실제 저장/수정/삭제, 플레이어 변경, 참여자 추가가 활동입니다. 조회, 동일 점수 재저장, 동일 성공 요청 재전송, 개인 입력 대상/정렬, 초대만 보내기, 종료 권한 변경은 연장하지 않습니다.

- 10분 간격 Cron이 앱 실행 여부와 관계없이 만료 라운드를 종료합니다.
- API가 만료 라운드에 접근하면 Cron을 기다리지 않고 동일한 종료 트랜잭션을 수행합니다.
- 실제 쓰기 검사에도 D1 현재 시각과 6시간 기한을 포함합니다. 만료 검사와 저장 사이의 경쟁에서 기한이 지난 쓰기를 허용하지 않습니다.
- 자동 종료의 `ended_at`은 Cron 처리 시각이 아니라 마지막 변경 +6시간입니다. 추후 종료+24시간 수정 기한도 이 값을 사용해야 합니다.
- 만료 라운드가 스케줄에 의해 DB에서 최종 정리되기까지 통상 다음 Cron 주기까지 지연될 수 있습니다. API는 그 구간에도 진행 중 쓰기를 허용하지 않습니다.

종료된 라운드에서 허용했던 미등록 이름 수정은 유지하지만 종료 시각과 활동 기준 시각을 바꾸지 않습니다. 다른 점수 입력은 현재 모두 거절합니다.

## 앱의 미저장 보호

종료 화면은 현재 홀뿐 아니라 해당 라운드의 모든 홀을 확인합니다. 초안과 전송 대기·충돌·권한 보류를 따로 표시하고 해당 홀로 돌아갈 수 있습니다.

초안은 모두 저장 후 전송, 초안만 명시적으로 버리기, 계속 입력을 선택합니다. 확인 대화상자 동안 다른 탭에서 초안이 바뀌면 버리기를 거절합니다. 이미 큐에 들어간 요청은 결과가 불명확하므로 버리는 버튼이 없습니다. 충돌은 기존 점수 화면에서 최신 값 확인/거절을 끝내야 합니다.

모든 초안/큐가 비었을 때 종료 요청을 점수 저장소 안에 원자적으로 기록합니다. 이 체크포인트가 있는 동안 다른 탭도 새 점수를 입력/전송할 수 없습니다. 연결 장애나 앱 종료 후에도 원래 사용자·요청 ID·확인한 버전을 그대로 재시도합니다. 서버 성공과 로컬 확인 저장까지 끝나야 완료 처리합니다. 서버가 기록 변경/권한 거절을 확정하면 다시 확인하도록 잠금을 풀며, 불명확한 오류는 요청을 유지합니다.

다른 참여자 기기의 오프라인 초안은 서버가 알 수 없습니다. 종료 확인에 동반자의 미전송 점수를 확인하도록 안내합니다. 자동 종료나 다른 참여자의 종료가 먼저 완료된 경우 이 기기의 초안/큐를 그대로 보관하며, 늦은 점수 수용 정책을 임의로 만들지 않습니다.

## 화면과 후속 범위

진행 중 현황 및 점수 화면 → 종료 확인/권한 관리 → 종료 결과/스코어카드. 이 흐름에는 배너를 표시하지 않습니다. 홈에 최근 종료 10개를 제공하고 라운드 원본을 조회합니다. 개인 기록 받기/보내기·삭제는 7단계이며 이 목록을 RECEIPT로 취급하지 않습니다.

9홀 전체 입력도 완료로 표시하지만 개인 통계 대상은 아닙니다. 한 사람이 미완료여도 다른 플레이어의 완료 여부는 독립적입니다. 8단계 본인 수정은 현재 스코어와 개인 통계의 완료 기준을 다시 계산해야 하며, 이번 테이블은 종료 당시 상태로 보존합니다.
