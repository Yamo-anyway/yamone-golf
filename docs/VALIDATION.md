- 기존 v0.2.0 ZIP의 SHA-256 유지.

## 3단계 핵심 검증

1. 같은 닉네임 두 사용자를 개인 코드/user_id로 구분. 코드와 개인 QR 텍스트가 같은 사용자를 가리킴.
2. 외부 URL·복구 키·UUID·추가 쿼리가 붙은 QR을 개인 코드로 받지 않음.
3. 사용자 확인 후 슬롯 연결. 연결만 된 비참여자는 진행 중 라운드에 등록되거나 광고 이력이 생기지 않으며 관리 API 권한도 얻지 않음.
4. 한 라운드에서 같은 사용자를 두 슬롯에 동시에 연결할 수 없음. 동시에 같은 슬롯 이름을 수정하면 하나만 성공.
5. 연결 사용자 닉네임이 바뀌면 표시명도 갱신. 연결 중 임시 이름 변경은 거절.
6. 연결 해제 후 슬롯 ID·스코어·개인 입력 대상 유지, 새 임시 이름과 이후 이름 수정 허용.
7. 동시 추가·응답 유실 재시도에서 중복 슬롯 없음, 활성 슬롯 최대 8명. 같은 요청 ID에 다른 내용은 거절.
8. 개인 입력 대상은 사용자별 독립. 순서·선택을 저장하고 다른 사용자에게 영향 없음. 0명 선택도 재실행 후 그대로 유지.
9. 개인 입력 목록 저장은 공동 라운드 updated_at을 변경하지 않음. 다른 라운드 슬롯이나 오래된 목록 버전은 거절.
10. 사용자 연결·실제 점수·취소된 전송·삭제 상태의 수신 참조가 있는 슬롯 삭제 거절. 마지막 한 명도 보호.
11. 안전한 삭제는 원본 슬롯의 식별자/감사 이력을 보존하고 개인 입력 목록 참조만 정리. 영향받는 목록 버전 증가.
12. 삭제 확인 이후 입력 목록·스코어가 바뀌면 서버가 다시 검사. 오래된 개인 선택으로 삭제된 슬롯을 되살릴 수 없음.
13. 종료된 라운드에서는 미등록 이름 변경만 허용. 슬롯 추가·연결·해제·삭제·입력 대상 변경은 거절.
14. 기기 복구 뒤 연결 user_id와 개인 입력 목록 유지. 기존 기기의 수정 요청 차단.
15. 화면 갱신/다른 참여자의 이름 수정 후에도 작성 초안 유지. 충돌 안내 후 사용자가 최신 내용을 선택해야 초안 교체.
16. 실제 마우스 드래그와 위/아래 정렬. 저장 전에는 서버 순서가 바뀌지 않고 저장 후 재실행 시 유지.
17. 한국어 화면 및 320px 영어 빈 선택 화면에서 가로 넘침 없음. 입력 대상 화면의 반복 설명을 줄여 플레이어 목록을 더 빨리 볼 수 있도록 조정.

## 기존 흐름 회귀 확인

닉네임 시작·중복 허용, 저장 실패 시 요청 차단, 등록 응답 유실 재시도, 복구 키 교체·동시 사용·기존 기기 비활성화, 웹 쿠키와 Origin, 공용 골프장/개인 목록, 골프장 수정 충돌, 라운드 생성 복사본, 한 사용자당 진행 중 라운드 1개, 초대 취소/재초대/참여, 코드 참여, 광고 중단/장애/처리 재개, 세 사용자의 동일 라운드 열람.

## 화면 캡처

`qa/stage-3/`에 사용자 연결 확인, 보호된 슬롯, 수정 초안 보존, 개인 입력 대상, 영어 빈 목록 캡처가 있습니다. 캡처를 직접 확인했습니다. `qa/stage-1/`, `qa/stage-2/`에는 기존 흐름도 포함합니다.

캡처 환경의 한글 글꼴만 Noto Sans KR로 보완했습니다. 앱은 시스템 글꼴을 사용합니다. 테스트 사용자/골프장/스코어·전송·수신 참조는 격리된 테스트 DB에서만 생성했습니다.

## 남아 있는 실제 환경 검증

- QR 스캔 UI·Expo Camera 연결·권한 구성·Android 번들은 구현/검사했습니다. 실기기 카메라 인식률, 권한 거절/재허용, 백그라운드 복귀, 터치 드래그는 아직 실제 휴대폰에서 검증하지 않았습니다. 웹 검증은 코드와 QR 텍스트 입력을 사용했습니다.
- Android export는 APK 설치 빌드가 아닙니다. iOS/Android SecureStore의 재부팅·업데이트·삭제/재설치도 실기기 확인이 남아 있습니다.
- 실제 Cloudflare 계정/DB 생성·배포, 원격 Git push, 실제 광고 SDK·배너, Resend는 이번 범위에 없습니다.
- scores/deliveries/receipts는 삭제 보호를 위해 구조를 먼저 두었습니다. 점수·종료·자동 종료·기록 보내기/받기·통계 화면/API는 후속 단계입니다.
- 이름 초안은 화면 갱신·이동 보호 범위입니다. 앱 강제 종료까지 모든 이름 초안을 복원하는 기능은 없습니다. 점수 초안·오프라인 저장은 5단계입니다.
- 이전 단계의 외부 배포 사전 검증은 자동 승인 검토에서 차단되었으며, 이번에는 해당 명령을 실행하지 않았습니다. 서버 검증은 로컬 D1과 Miniflare만 사용했습니다.
