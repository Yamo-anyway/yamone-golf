## 8단계 핵심 검증

1. received 기록의 현재 본인 슬롯만 수정. 다른 수신자, 기록자/생성자의 타인 점수 수정, user_id 바꿔치기와 폐기 기기 거절.
2. 종료+24시간 미만만 새 수정 가능. 정확한 경계에서 차단하며 수신 시각과 무관. 수정해도 ended_at/updated_at을 연장하지 않음.
3. 서버 성공 후 기한 만료·개인 삭제가 발생해도 동일 요청의 성공은 재확인. 다른 본문으로 요청 ID 재사용 시 거절.
4. 연결 해제 후 수정 차단. 같은 사용자 재연결도 기존 슬롯 버전의 새 쓰기 거절. 최신 확인 이후에만 새 수정 가능.
5. 같은 값은 점수/감사 버전 불변. 충돌 재확인 중 값이 바뀌면 재확인. 동시 다른 값 저장에서 하나만 반영되며 예전 성공 요청은 새 값을 덮어쓰지 않음.
6. 실제 쓰기 배치 직전 종료 기한·개인 삭제·연결을 바꾸는 경쟁 주입으로 SQL 재검사와 전체 롤백 확인.
7. null 삭제/미입력 채우기 후 현재 완료 여부와 통계가 바뀜. 종료 당시 round_completions Snapshot은 보존. 다른 선수의 미완료는 본인 18홀 통계를 제외하지 않음.
8. 9홀·미수신·개인 삭제·현재 연결 해제는 통계 제외. 개인별 집계 격리와 여러 라운드 평균/최저/최고/PAR 분포 확인.
9. 공용 골프장 PAR 수정이 과거 Snapshot 기반 통계에 영향을 주지 않음. 통계가 없을 때 평균 등은 null.
10. 검색의 %/_는 와일드카드가 아닌 검색 문자로 처리. 목록 필터, 사용자 격리, 잘못된 커서/입력값 거절. 기존 23개 커서 페이지 검증도 통과.
11. 다중 홀 초안, 마지막 홀, 저장되지 않은 PAR/null 상태와 재실행 복원. 조회로 초안/원래 버전을 덮어쓰지 않음.
12. 요청 전 저장 실패는 서버 전송하지 않음. 응답 유실/로컬 확인 저장 실패/재실행 후 같은 요청을 유지. 결과 미확정 요청은 버리거나 바꾸지 않음.
13. 충돌 거절 시 해당 홀만 최신 값을 적용하고 다른 홀 초안 보존. 확정 거절은 값 보관 후 명시적 폐기 가능. 자동 전송 없음.
14. 저장소 사용자 격리, 동시 로컬 변경 직렬화, 손상된 데이터 원본 보존. 기존 진행 중 오프라인 큐를 본인 수정으로 자동 전환하지 않음.

## 화면 검증

로컬 Worker/D1과 브라우저로 완성된 본인 18홀과 미완료 동반자의 라운드를 구성했습니다. 통계 72타, 없는 골프장 검색, 통계 필터, 본인 수정 진입, 저장/보관/계속 입력 이동, 여러 홀 초안의 새 탭 재실행, 두 차례 충돌과 최신 적용, 응답 유실 후 원래 요청 확인을 검증했습니다.

다른 수신자의 원본 열람에도 수정 점수가 반영되고, 본인 null 삭제는 통계 제외, 다시 채우기는 통계 포함입니다. 연결 해제 중 수정은 거절하면서 초안은 유지하고, 명시적 취소 후 재연결하면 최신 권한을 확인합니다. 홈 이동/수정 이어서, 320px 영어 통계·수정 화면의 가로 넘침도 확인했습니다.

화면 검증 중 로컬 preview 프록시가 URL의 검색 문자열을 전달하지 않던 문제를 수정했습니다. 검색/필터/커서/user_id 파라미터를 이제 그대로 전달하며 없는 검색어의 빈 결과까지 확인합니다. 초안 재실행 테스트는 기기 저장 성공이 화면에 반영된 뒤 탭을 닫도록 하여 입력 이벤트와 영속 저장 완료를 구분합니다.

전체 UI 실행에서 테스트 묶음들이 신규 사용자 생성 한도를 공유하던 문제를 확인해 묶음마다 새 격리 D1을 사용하도록 실행기를 수정했습니다. 실제 서비스의 생성/요청 제한은 그대로 유지합니다.

`qa/stage-8/`에 통계, 복원된 초안, 최신 값 재확인, 연결 해제 보류, 영어 320px 화면을 보관합니다. 임의 테스트 이름을 사용했으며 이전 단계 캡처도 소스 ZIP에 포함합니다.

## 남은 검증

실제 Android/iOS 설치·OS 강제 종료·재부팅·망 전환 검증은 아직 아닙니다. 앱 삭제로 사라진 미전송 초안 복구는 제공하지 않습니다. 브라우저 검증은 영속 저장 완료 뒤 새 탭 재실행과 응답 유실 재시도를 포함합니다.

실제 광고 SDK/배너, 이메일/Resend, 외부 Cloudflare 계정·리소스 생성과 배포는 수행하지 않았습니다. 통계/받은 기록은 온라인 조회이며 기기 초안 보관과 서버 저장 완료를 구분합니다. 다음은 신페리오 단계이고 계산 3시간 기준점·실행 권한은 여전히 미확정입니다.
