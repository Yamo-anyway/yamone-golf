# 7단계 검증 결과 — v0.3.6 / 2026-09-23

## 검증 범위

- 앱·Worker TypeScript 및 Expo ESLint 통과.
- Worker/D1 **62개** + 앱 저장/오프라인/광고/수신 흐름 **37개** = **99개 테스트** 통과.
- 브라우저 UI 7묶음: 인증, 라운드, 플레이어, 점수, 오프라인, 종료, 기록 전달.
- 기존 개발 D1에 0006 마이그레이션 적용. 격리 환경에서 0001~0006 순차 적용과 기존 생성 광고 이력 보존 업그레이드 검증.
- Expo Web 및 Android Hermes export. 설치 APK·실제 휴대폰 검증과는 구분합니다.

## 기록 전달 핵심 검증

1. 종료된 라운드의 기존 참여자만 보내기·연결 관리 가능. 개인 코드/QR 연결은 참여자 등록과 별개이며 종료 후 슬롯 추가·삭제는 차단.
2. 같은 보내기 요청 재시도, 다른 요청으로 이미 pending인 전송 재전송, 잘못된 사용자·슬롯 버전·요청 ID 재사용 검증.
3. 비참여 수신자는 광고 처리 후 전체 라운드 조회 가능. 다른 사용자의 RECEIPT·기록 목록은 접근 불가. 공동 입력 권한은 추가되지 않음.
4. 생성자/참여자는 기존 광고를 재사용. 다른 진행 중 라운드가 있어도 종료 기록을 받으며 활성 라운드 관계를 변경하지 않음.
5. 광고 중 앱 종료는 수신·광고 완료로 인정하지 않음. 완료/장애 결과는 먼저 기기에 저장하고 서버 실행과 분리.
6. 광고 중 전송 취소 또는 연결 해제 시 실제 수신은 거절하되 처리한 광고 이력은 유지. 후속 새 전송은 추가 광고 없음.
7. 완료 증거 등록의 통신 실패 후 수신 화면을 나갈 때도 광고 이력 확인을 먼저 수행. 실패하면 증거를 보존하고, 성공해도 기록을 자동으로 받지는 않음.
8. 수신 동시 요청·다른 action으로 같은 전송 수신·취소/연결 해제와의 경쟁에서 RECEIPT 중복 생성 및 늦은 수신 차단.
9. 개인 기록 삭제는 원본/다른 사람 기록을 보존. 삭제한 결과의 과거 수신 재시도는 deleted를 반환하며 재생성하지 않음.
10. 새로운 명시적 보내기만 새 수신 항목 생성. 예전 삭제 요청이 나중의 새 RECEIPT에 영향을 주지 않음. 홈 최근 종료 항목으로도 삭제 기록을 되살리지 않음.
11. 연결 해제는 pending 전송만 취소. 이미 수신한 기록은 원래 소유자에게 남으며 current_player는 현재 연결 상태와 분리해 반환.
12. 잘못된 사용자 요청, 비참여자 관리, 폐기 기기, 운영 환경의 테스트 광고 결과를 거절. 다섯 완료/장애 결과 모두 같은 라운드의 광고 이력 하나만 생성.
13. 같은 시각에 생성된 23개 전송·수신 기록을 20개 커서로 누락/중복 없이 조회. 사용자별 목록 격리.
14. 앱 재실행, 응답 유실, 로컬 저장/확인 실패, 동시 선택, 오래된 확인 응답, 손상된 보류 데이터에서 원래 요청을 보존.
15. 마이그레이션 전 실제 생성 action/광고 이력을 준비한 별도 DB에서 0006 적용 후 값과 외래키 무결성 유지.

## 화면 검증

실제 로컬 Worker/D1과 브라우저 UI를 사용했습니다. 종료 후 코드 연결, 전송, 광고 화면 중 탭 종료/재실행, 광고 결과 등록 실패 후 수신하지 않고 돌아가기, 수신 성공 응답 유실 후 새 탭 재시도, 전체 3명 점수 열람, 개인 기록 삭제, 새 전송 재수신, 생성자 추가 광고 없음, 보낸 사람의 전송 취소, 320px 영어 화면을 검증했습니다.

전체 실행에서 기존 인증·라운드·플레이어·점수·오프라인 5묶음을 통과했습니다. 종료 테스트는 저장된 active 캐시가 먼저 보이는 시점에 즉시 비교하던 부분을 서버의 ended 상태 반영 대기로 수정하고 종료·기록 전달을 다시 통과했습니다. 기록 전달 테스트의 재방문 선택자는 Router가 보존하는 숨겨진 이전 화면 대신 현재 보이는 화면을 검사합니다. 수신 취소 보강 후 해당 기록 전달 묶음을 추가로 검증했습니다.

`qa/stage-7/`에 종료 후 전송, 첫 수신 광고, 전체 라운드, 삭제 후 빈 목록, 영어 화면을 보관합니다. 테스트 이름은 임의 데이터입니다. 이전 단계 캡처도 소스 ZIP에 포함합니다.

## 범위와 남은 검증

브라우저의 새 탭으로 메모리 없이 재실행하는 경우를 확인했지만 실제 Android/iOS OS 강제 종료·재부팅·망 전환 검증은 아직 아닙니다. 실제 광고 SDK·배너, 이메일/Resend, 외부 Cloudflare 계정·DB 생성/배포도 남아 있습니다. 개발 광고 어댑터의 테스트 결과는 실제 광고 노출 검증을 의미하지 않습니다.

기록 목록/전체 열람은 온라인 기능입니다. 신페리오 이력은 아직 빈 배열이며 9단계에서 연결합니다. 개인 통계·종료+24시간 본인 수정은 다음 8단계입니다.

종료 후 늦게 도착한 오프라인 점수는 보류하고 원래 값을 보관합니다. 수용 정책, 나가기 및 사용자 데이터 삭제 정책은 임의로 확정하지 않았습니다. 개인 RECEIPT 삭제는 사용자 계정 삭제와 별개입니다.
