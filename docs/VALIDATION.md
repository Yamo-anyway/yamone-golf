## 4단계 핵심 검증

1. 새 점수는 행 없음/null이며 0을 저장하지 않음. 홀 단위 저장, 기존 기록 수정, null 삭제와 증가한 버전/변경 이력.
2. 한 플레이어라도 다른 최신 값이면 전체 홀 저장 보류. 미저장 점수는 서버에 부분 반영되지 않음.
3. 확인 중 다른 참여자가 다시 수정하면 최신 점수를 재확인. 값이 4→5→4로 돌아와도 오래된 버전의 다른 값 쓰기는 충돌.
4. 동일 값의 동시 입력은 모두 성공하지만 버전/이력/라운드 갱신 시각은 중복 변경되지 않음.
5. 동시 다른 값 입력은 하나의 완전한 홀 저장만 성공. 삭제 후 오래된 입력은 null tombstone 버전과 충돌.
6. 응답 유실/동시 재시도에서 한 번만 실행. 다른 참여자의 후속 수정을 오래된 요청 재시도가 덮어쓰지 않음. 요청 ID의 다른 내용 재사용 거절.
7. 현재 선택된 입력 대상 전체만 저장. 개인 목록 버전/플레이어 목록 변화, 다른 슬롯/중복 슬롯, 0/음수/소수/문자열/범위 밖 홀 거절.
8. 비참여자, 이전된 기기, 종료된 라운드, 삭제된 플레이어는 쓰기 불가. 신뢰 Origin의 PUT CORS 사전 요청 허용.
9. 첫 진입 1번 홀, 마지막 열었던 홀 재실행 복귀, 저장된 위치가 없을 때 첫 미입력 홀 탐색.
10. PAR 기본값·저장 전·서버 저장 완료 구분. 화면 조회가 미저장 점수를 바꾸지 않음.
11. 직접 홀 선택/이전·다음/화면 이동 보호. 저장 후 이동, 버리고 이동, 계속 입력. 홈 탭도 같은 보호 적용.
12. 충돌 거절 시 해당 행만 최신 값 적용, 다른 플레이어 초안 유지. 연속 충돌도 다시 확인.
13. 서버에 실제 저장된 뒤 응답이 끊어진 경우 현재 홀/초안을 유지하고 재시도 성공. 실패를 완료로 표시하지 않음.
14. 선택 대상 홀 삭제 및 미입력 표시. 누적 합계 오름차순, 공동 순위 1,1,3, 미입력은 순위 제외, 개인 입력 순서 유지.
15. 전반/후반 9홀+합계, 원/박스/이중 박스 표시. 320px 영어 화면의 가로 넘침 검사와 캡처 육안 확인.

## 기존 흐름

닉네임 생성·중복 허용, 키 복구·기존 기기 비활성화, 웹 인증/Origin, 골프장 공용 수정/개인 목록, 한 사용자 진행 중 라운드 1개, 생성/초대/참여, 개발용 광고 중단/실패/응답 유실 재개, 플레이어 코드/QR 연결·해제·삭제 보호, 개인 입력 목록 선택·정렬·드래그의 기존 테스트도 포함합니다.

## 캡처와 한계

`qa/stage-4/`에 1번 홀, 이동 확인, 점수 충돌, 한국어/320px 영어 스코어카드와 입력 화면을 저장합니다. `qa/stage-1/`~`stage-3/`의 이전 검증 캡처도 포함합니다. 한글 테스트 캡처만 Noto Sans KR을 사용하며 앱은 시스템 글꼴입니다.

실제 휴대폰 터치/뒤로가기/카메라/앱 종료·재부팅·업데이트·재설치, Android/iOS 설치 빌드, Cloudflare 계정/DB 생성·배포, 실제 광고와 Resend는 아직 검증/연결하지 않았습니다. 이전 외부 배포 사전 검증은 자동 승인 검토에서 차단되었고 이번 단계도 로컬 검증만 수행합니다.

현재 화면의 점수 초안은 앱 강제 종료까지 복원되지 않습니다. 여러 홀 초안·오프라인 큐는 5단계입니다. 종료/자동 종료는 6단계, 보내기/받기는 7단계, 종료 후 24시간 본인 수정은 8단계입니다. 종료 후 늦게 도착한 오프라인 기록 정책은 미확정입니다.
