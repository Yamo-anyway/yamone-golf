# 5단계 검증 결과 — v0.3.4 / 2026-09-23

## 검증 범위

- 앱·Worker TypeScript 및 Expo ESLint.
- Worker/D1 39개 + 앱 저장/오프라인/정렬/광고 정책 26개 = **65개 테스트**.
- 실제 Worker/D1 브라우저 UI 5묶음: 사용자 인증, 라운드, 플레이어/입력 대상, 점수, 오프라인 복구.
- Expo Web 및 Android Hermes export. 설치 APK·실제 휴대폰 검증과는 구분합니다.
- 기존 D1 0001~0004 사용, 이번 단계 새 DB 마이그레이션 없음.

## 오프라인 핵심 검증

1. 여러 홀의 승인된 +/- 변경과 마지막 홀을 디스크에 기록하고 새 컨트롤러/화면에서 복원.
2. 빠른 연속 입력과 조회가 겹쳐도 변경을 잃지 않음. 작성 중 초안을 서버 조회가 바꾸지 않음.
3. 기기 저장 실패 시 새 값을 표시하거나 전송하지 않음. 이전 초안과 디스크 원본 보존. 취소 동작의 저장 실패도 기존 초안 유지.
4. 서버 요청을 하기 전에 원래 mutation_id/user_id/값/버전을 기록. 초안은 자동 업로드하지 않음.
5. 오프라인 새로고침, 홈 진입, 탭 종료 후 새 앱 인스턴스로 복귀해 대기 요청과 초안 유지.
6. 성공 응답 유실 후 재실행에서 같은 요청 재전송. 그 사이 다른 기록자의 새 점수를 과거 요청이 덮어쓰지 않음.
7. 서버 성공 후 로컬 확인 저장 실패에서도 원래 요청 유지·안전한 재확인.
8. 충돌한 홀만 보류하고 다른 홀 전송 성공. 충돌 상태 재실행 복구와 재확인 도중 추가 변경 검출.
9. 충돌 거절은 해당 행만 최신 값으로 바꾸고 다른 초안은 영속 보관. 확인을 미루고 다른 홀 입력 가능.
10. 결과 미확정인 홀은 값 변경/다른 삭제 요청으로 교체하지 않음.
11. 종료 라운드의 늦은 요청은 보류·원래 값 유지, 자동 재시도 중단. 서버의 종료 판단을 받은 뒤 신규 입력 잠금.
12. 대상 목록 변경으로 보류한 뒤 명시적 다시 준비. 기존 점수 버전 유지 및 이후 충돌 재검사. 삭제 의도 유지.
13. 사용자별 저장소 분리. 손상 JSON·다른 사용자 형식은 원본을 덮어쓰지 않음. 비활성 저장 컨트롤러는 전송하지 않음.
14. 두 동기화 호출이 겹쳐도 한 요청만 전송. 두 웹 탭의 동시 수정도 사용자별 잠금과 최신 디스크 읽기로 보존.
15. 서버는 오프라인 요청 원래 사용자와 현재 인증 사용자가 다르면 거절. 같은 라운드에 참여 중인 다른 사용자도 원래 큐를 대신 전송할 수 없음.
16. 기기 초안/전송 대기/서버 기록 구분. 서버 기록만 스코어카드 합계·순위에 표시. 320px 영어 화면 가로 넘침 없음.

## 회귀 확인

기존 사용자 생성·복구·기기 폐기, 공용 골프장/개인 목록, 한 사용자 진행 중 라운드 1개, 생성·초대·참여와 개발 광고 중단/재개, 플레이어 연결/해제/삭제 보호, 입력 대상 선택/정렬, 점수 원자적 저장·충돌·삭제·공동 순위도 통과합니다.

4단계 UI의 ‘통신 실패 시 항상 현재 홀 유지’는 5단계의 영속 큐 규칙으로 바뀌었습니다. ‘저장 후 이동’에서 기기 대기열 저장이 끝났다면 전송 대기로 표시하고 이동합니다. 로컬 저장 실패 또는 미확정 충돌은 이동하지 않습니다.

## 화면과 검증 한계

`qa/stage-5/`에 여러 홀 초안, 오프라인 재진입, 복구한 충돌, 저장 실패, 320px 영어 화면을 보관합니다. 캡처를 확인해 상태 안내를 간결하게 하고 상세 안내는 입력 목록 아래로 이동했습니다. 이전 단계 캡처도 포함합니다.

브라우저 테스트의 오프라인은 앱 정적 파일을 로드할 수 있는 상태에서 API만 차단합니다. 탭 종료 후 새 인스턴스 진입으로 메모리 없이 복구하는 경우를 확인했지만 실제 Android/iOS OS 강제 종료 검증은 아직 아닙니다. PWA 앱 자체의 오프라인 배포는 구현하지 않았습니다.

실제 비행기 모드·망 전환·재부팅/업데이트·설치/삭제·카메라·휴대폰 터치, Cloudflare 실제 계정/DB 생성·배포, 실제 광고 SDK·배너, Resend는 남아 있습니다. 이전 외부 배포 사전 검증은 자동 승인 검토에서 차단되었으며 이번도 로컬만 검증했습니다.

종료 후 늦게 도착한 오프라인 점수 정책은 미확정이며 자동 반영하지 않습니다. 사용자 데이터 삭제 정책과 기기 캐시 장기 정리도 출시 전에 확정해야 합니다.
