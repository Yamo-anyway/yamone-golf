# 6단계 검증 결과 — v0.3.5 / 2026-09-23

## 검증 범위

- 앱·Worker TypeScript 및 Expo ESLint.
- Worker/D1 **49개** + 앱 저장/오프라인/정렬/광고 정책 **31개** = **80개 테스트**.
- 브라우저 UI 6묶음 통과: 인증, 라운드, 플레이어, 점수, 오프라인, 종료.
- 기존 개발 D1에 0005 마이그레이션 적용 성공. 테스트 환경에서도 0001~0005를 순서대로 적용.
- Expo Web 및 Android Hermes export. 설치 APK·실제 휴대폰 검증과는 구분합니다.

## 종료 핵심 검증

1. 생성자만 권한 부여/회수, 위임받은 참여자만 종료. 비참여자, 다른 사용자 요청, 폐기된 기기는 거절.
2. 종료 확인 중 점수, 플레이어 이름, 참여자 변경을 버전으로 감지. 같은 점수 재저장은 버전과 활동 시각을 늘리지 않음.
3. 동시 종료/응답 유실 재시도는 라운드 종료 이력을 한 번만 생성. 같은 요청 ID의 다른 본문은 거절.
4. 종료 시 점수·플레이어 보존, 모든 해당 참여자의 진행 중 제한 해제, 대기 초대 취소, 추가 광고 이력 없음.
5. 실제 scheduled 핸들러 호출로 6시간 자동 종료 확인. 종료 기준 시각은 마지막 기록 변경 +6시간. 새로 갱신된 라운드는 유지.
6. Cron 전 만료 점수·참여 요청도 차단하고 API 접근에서 종료 정리. 새 라운드 생성 가능.
7. 18홀 완료/미완료 및 9홀 완료/미완료를 플레이어별 독립 저장. null 삭제는 미완료로 처리.
8. 점수 대 종료, 참여 대 종료 경쟁에서 뒤늦은 활성 참여/점수 쓰기 없음. 이전 종료 재전송이 새 라운드의 활성 참여를 지우지 않음.
9. 만료 직후 임시 이름 수정은 먼저 자동 종료 처리. 종료 후 이름 수정은 종료 시각·활동 기준 시각을 바꾸지 않음.
10. 모든 홀의 초안·큐·충돌이 종료를 막음. 보관한 요청은 결과 확인 전에 버리지 않음.
11. 종료 요청을 디스크에 쓰기 전에는 서버로 보내지 않음. 종료 응답 유실·로컬 확인 저장 실패·재실행 후 원래 요청 ID/버전 유지.
12. 종료 체크포인트가 있으면 다른 탭도 입력 불가. 초안 버리기 확인 중 다른 편집기 변경을 감지. 늦은 과거 active 응답이 확인된 종료를 다시 열지 않음.

## 화면 검증

실제 로컬 Worker/D1과 브라우저 UI를 사용했습니다. 종료 위임, 모든 홀의 초안 확인/저장, 다른 사용자의 점수 변경 후 재확인, 서버 성공 응답 유실 후 새 탭 재실행/종료 결과 재확인, 홈 종료 라운드 진입, 읽기 전용 스코어카드, 320px 영어 화면을 검증했습니다.

기존 점수 UI 테스트의 충돌 거절 직후 즉시 비교를 영속 저장 후 화면 값 갱신 대기로 수정했습니다. 해당 점수·오프라인·종료 묶음을 다시 실행해 통과했고, 앞서 통과한 인증·라운드·플레이어 묶음과 함께 전체 6묶음을 확인했습니다.

`qa/stage-6/`에 종료 권한, 초안 보호, 최신 확인, 종료 복구, 영어 화면을 보관합니다. 사용자 이름은 임의 테스트 데이터입니다. 이전 단계 캡처도 소스 ZIP에 포함합니다.

## 범위와 남은 검증

브라우저의 새 탭으로 메모리 없이 재실행하는 경우를 확인했지만 실제 Android/iOS OS 강제 종료·재부팅·망 전환 검증은 아직 아닙니다. 실제 광고 SDK·배너, 이메일/Resend, 외부 Cloudflare 계정·DB 생성/배포도 남아 있습니다.

Cron은 로컬 런타임의 실제 scheduled 핸들러로 검증했습니다. 외부 Cloudflare 스케줄이 이미 가동 중이라는 의미는 아닙니다. 이전 외부 배포 사전 검증이 자동 승인 검토에서 차단된 이후 이번 단계도 로컬 검증만 수행했습니다.

종료 후 늦게 도착한 오프라인 점수는 보류하고 원래 값을 보관합니다. 수용 정책, 나가기 및 사용자 데이터 삭제 정책은 임의로 확정하지 않았습니다. 기록 보내기/받기는 다음 7단계입니다.
