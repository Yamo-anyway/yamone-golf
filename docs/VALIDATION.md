## 이번 단계에서 확인한 동작

1. 공용 골프장 등록·검색·수정, 개인별 목록 추가·제거·순서 저장. 다른 사용자의 목록과 공용 원본에 영향 없음.
2. 두 공용 수정이 같은 버전에서 경쟁하면 하나만 성공. 앱은 충돌 시 작성 초안을 남기고 사용자가 선택해야 최신 내용으로 교체.
3. 내 골프장 위/아래 및 실제 마우스 드래그 정렬, 새로고침 후 순서 유지.
4. PAR 범위, 9홀 구성, 플레이어 인원/이름, 코스 버전 검증.
5. 동일 9홀을 두 번 선택하는 18홀 라운드, 생성자가 실제 플레이하지 않는 기록자 역할.
6. 골프장 수정 후에도 기존 라운드의 이름·코스·PAR 복사본 유지.
7. 동시 생성/참여 요청에서 진행 중 라운드 하나만 등록, 실패한 요청의 부분 데이터 롤백.
8. 광고 처리 전 실행 거절. interrupted 결과 거절, 개발 광고 화면에서 재실행해도 라운드가 생성되지 않음.
9. 장애로 처리한 광고는 완료로 인정. 같은 생성 요청 5개가 경쟁해도 라운드 1개와 사용자별 광고 이력 1개.
10. 광고 처리 뒤 서버 라운드 상태가 종료로 바뀌면 참여 거절, 광고 완료 상태는 보존.
11. 생성 응답을 의도적으로 끊은 후 앱을 새로 열어 광고 재처리 없이 같은 라운드로 복귀.
12. 홈 초대 카드 취소 후 진행 중 라운드 없음, 새 초대 수신·참여. 취소한 과거 카드가 스스로 다시 나타나지 않음.
13. 생성자·초대 참여자·코드 참여자 세 사용자에게 동일 라운드 표시. 참여자 3명과 실제 플레이어 2명 구분.
14. 비참여자의 원본 열람/초대 거절, 다른 사용자의 광고 처리 요청 거절, 폐기된 기기의 공용 수정 거절.
15. 화면 진입·복귀·명시적 새로고침으로 갱신. 홈 이동 시 같은 홈 화면이 중복으로 쌓이지 않도록 보완.
16. 일본어 기기 설정에서 영어 선택, 320px 골프장 검색 화면 가로 넘침 없음.

## 아직 검증하지 않은 범위

- 실제 광고 SDK/전면 광고 생명주기와 배너, Resend, 이메일, Cloudflare 원격 리소스 생성·배포, 원격 Git push.
- Android export는 APK 컴파일·설치 검증이 아닙니다. iOS/Android 실기기 저장소, 삭제/재설치, 터치 드래그는 실기기 검증이 남아 있습니다.
- 점수·종료·자동 종료·기록 보내기/받기·통계는 후속 개발 범위입니다. 현재 개발 라운드는 종료 기능을 연결하기 전까지 진행 중으로 남습니다.
- 운영 광고 endpoint는 미구현입니다. 현재 테스트 endpoint는 production 환경을 거절하며, 개발 결과를 실제 광고 시청 증거로 사용하지 않습니다.
- 이 환경에서 이전에 `wrangler dev`의 네트워크 인터페이스 조회 오류가 있었으므로, UI 검증은 같은 Worker/D1을 실행하는 Miniflare 서버로 수행했습니다.
- 1단계의 외부 배포 사전 검증 명령은 자동 승인 검토에서 차단되었습니다. 이번 단계에서는 원격 배포·사전 배포 검증을 요청하지 않고 로컬 검사만 수행했습니다.
