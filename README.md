# Yamone Golf v0.3.3 — Cloudflare 개발 4단계

홀별 스코어 입력·수정·삭제, 동시 입력 충돌 확인, 누적 순위와 스코어카드를 추가한 개발판입니다. 기존 v0.2와 1·2·3단계 소스/태그를 보존합니다.

## 이번 단계에서 추가한 기능

- 새 라운드는 1번 홀부터 시작합니다. 다시 들어오면 해당 사용자가 마지막으로 열었던 홀, 저장된 위치가 없으면 첫 미입력 홀을 엽니다.
- 전반/후반, 홀 선택, PAR, 공통 저장/수정/취소/삭제 버튼, 개인 입력 대상 순서의 간결한 플레이어 행을 제공합니다.
- 미입력은 null이며 PAR 기본 표시·저장 전 변경·서버 저장 완료를 구분합니다. 저장을 누르면 조정하지 않은 PAR 기본값도 선택된 대상 전체에 저장합니다.
- 다른 홀·이전/다음·다른 화면·뒤로가기·홈 이동에 ‘저장 후 이동 / 저장하지 않고 이동 / 계속 입력’을 제공합니다. 저장 실패나 충돌 상태에서는 이동하지 않습니다.
- 서버는 선택된 대상 전체를 원자적으로 저장합니다. 다른 값이 먼저 저장됐다면 아무 점수도 바꾸지 않고 최신 값과 변경할 값을 돌려줍니다. 확인 도중 또 변경되면 다시 확인합니다. 충돌 거절 시 해당 점수만 최신 값으로 바꾸고 다른 초안은 남깁니다.
- 점수 삭제는 선택한 플레이어의 현재 홀만 null로 변경합니다. 삭제 후에도 버전과 변경 이력이 남습니다. 동일 값 재저장은 라운드 갱신 시각을 연장하지 않습니다.
- 같은 요청의 재시도는 중복 처리하지 않습니다. 점수·선택 목록·플레이어 목록 버전, 참여/활성 기기/라운드 상태를 실제 저장 시 다시 검사합니다.
- 누적/홀별 순위는 낮은 타수부터, 동점은 공동 순위입니다. 미입력 플레이어는 순위에서 제외하며 입력 홀 수를 표시합니다. 전반/후반 9홀+합계는 가로 스크롤 없이 표시합니다.
- 버디 이하는 원 1개, 보기는 박스 1개, 더블보기 이상은 박스 2개로 표시합니다. 기존 빨강/파랑 색을 유지합니다.

1~3단계의 사용자·복구 키, 골프장, 라운드 생성/초대/참여, 플레이어와 개인 입력 목록 기능도 포함합니다. **광고는 개발 테스트 어댑터이며 실제 광고 SDK·배너는 아직 없습니다.** 스코어 입력/스코어카드 흐름에 광고를 추가하지 않았습니다. 이메일·Resend는 마지막에 연결합니다.

현재 점수 초안은 실행 중인 화면 메모리에서 보호합니다. 앱 강제 종료 후 복구·오프라인 큐·여러 홀 초안은 5단계입니다. 라운드 종료/자동 종료는 6단계이며, 종료 후 본인 점수 수정은 기록 수신 기능과 함께 8단계에서 연결합니다. 현재 개발 라운드를 종료하는 UI는 없습니다. 순서는 `docs/DEVELOPMENT.md`, 기준은 `docs/POLICY.md`를 참고하세요.

## 기존 버전과 구분

- 기존 v0.2.0 원본 ZIP을 `baseline/`에 그대로 보존했습니다. `SHA256SUMS`로 확인할 수 있습니다.
- 앱 개발판 식별자는 `com.yamone.golf.dev`입니다. 기존 `com.yamone.golf`와 함께 설치할 수 있습니다.
- 새 D1 사용자는 기존 Node/SQLite 서버 사용자와 별개입니다. 이전 서버 데이터를 자동 이전하지 않습니다.
- 원격 Git 저장소·Cloudflare 계정에 업로드하거나 운영 DB를 생성한 상태가 아닙니다.

## 로컬 실행

Node.js 24와 npm을 사용합니다. 저장소 루트에서:

```bash
npm ci
npm run db:local
npm run server
```

별도 터미널에서 웹 확인:

```bash
npm run export:web
npm run preview
```

브라우저로 `http://localhost:4173`에 접속합니다. preview 서버가 `/api`를 로컬 Worker의 8787 포트로 전달합니다. preview는 개발 검증용이며 운영 호스팅 서버가 아닙니다.

휴대폰 실행 시 `.env.example`을 `.env`로 복사하고 `EXPO_PUBLIC_API_URL`을 **개발 컴퓨터의 LAN 주소와 8787 포트**로 설정합니다. 휴대폰의 localhost는 컴퓨터가 아닙니다.

```bash
cp .env.example .env
npm start
```

필요하면 Worker를 `npm run dev --workspace yamone-golf-cloudflare -- --ip 0.0.0.0`으로 실행하고 같은 네트워크의 휴대폰에서 접근합니다. QR 스캔은 새 개발 빌드에서 실기기 검증이 필요합니다. Web/Android export만으로 APK·실기기 검증이 끝난 것은 아닙니다.

## 검증 명령

```bash
npm run typecheck
npm run lint
npm test
npm run export:web
npm run export:android
```

UI 검증은 웹 export 후 아래 명령으로 실행합니다. 테스트가 별도 포트의 Worker/D1과 preview 서버를 자동 실행하고 종료합니다. 테스트 DB는 메모리에 격리되어 개발 DB를 변경하지 않습니다.

```bash
npx playwright install chromium
npm run test:ui
```

테스트에는 사용자·기기 복구, 세 사용자의 라운드 참여, 플레이어/개인 입력 대상, 홀별 점수 충돌·미저장 보호·응답 유실·스코어카드 흐름이 포함됩니다.

설치된 Chromium을 사용할 때는 `PLAYWRIGHT_EXECUTABLE_PATH`로 실행 파일 경로를 지정할 수 있습니다.

## Cloudflare 연결

`yamone-golf-cloudflare/wrangler.jsonc`의 모든 0으로 된 DB ID는 로컬 개발용 자리표시자입니다. 배포 전 실제 개발·운영 D1 ID로 각각 교체해야 합니다. 구체적인 순서는 `docs/CLOUDFLARE.md`를 참고하세요.

현재 Cron은 만료된 요청 제한 데이터만 정리합니다. 6시간 라운드 자동 종료는 6단계에서 구현합니다.
